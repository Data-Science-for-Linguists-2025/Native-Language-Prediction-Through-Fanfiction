## Aim
This project aims to create classifiers (specifically Naive Bayes) to predict the native language of an author of English works of fanfiction on the website known as AO3 ([Archive of Our Own](archiveofourown.org)).  
This project used supervised machine learning using tools provided by [scikit-learn](https://scikit-learn.org/stable/index.html) and [stanza](https://pypi.org/project/stanza). (BS4)[https://pypi.org/project/beautifulsoup4/] and regular expressions were used to parse through the fics, which were gathered either mnaually or through [Scrapy](https://scrapy.org/).
